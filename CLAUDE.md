# CLAUDE.md

A playful Chinese zodiac analog using beans. **12 beans × 5 flavours × 6 forms = 360-combination cycle.**

See [README.md](README.md) for stack, architecture, routes, content schema, compatibility, state, and spirit-bean details. Read the relevant section before non-trivial work.

- Content is markdown in `src/content/`; JSON in `src/data/generated/` and `public/api/zodiacs/` is generated by `scripts/build-content.mjs` — never hand-edit it. Run `pnpm content` to refresh outside of `pnpm dev`/`pnpm build`.
